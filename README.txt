LIQUID WARDROBE — COMPLETE ANIMATED WEBSITE

OPEN / RUN
1. Extract this ZIP.
2. Open the extracted folder in VS Code.
3. Open index.html with Live Server.
4. Keep the folders and filenames intact.

FILES
- index.html: website sections and content
- style.css: responsive design and animations
- script.js: navigation, carousel, tutorial fallback, and demo review form
- images/logo.png: supplied Liquid Wardrobe logo used in header and footer
- images/hero-art.png: hero artwork
- videos/machine-video.mp4: put the final tutorial video here later

CLIENT ASSETS TO ADD LATER
- Machine photo: update the relevant image src in index.html to the client's machine photo.
- Product photos: replace the demo image URLs in the Products section with the client's own image files.
- Ordering QR: replace the QR placeholder in the contact section with images/order-qr.png after receiving a real scannable QR image.
- Tutorial: put the final video at videos/machine-video.mp4; the placeholder should hide when the video loads.
- Social links: in index.html search for animated-socials and replace the # links with confirmed Facebook, Instagram, TikTok, YouTube, WhatsApp, and Google review URLs.
- Email: replace hello@example.com with the confirmed business email.

REVIEWS IMPORTANT
The review form lets a visitor select 1–5 stars, add a name and feedback, and see reviews stored in that same browser using localStorage. It is a front-end demo; reviews do not automatically appear for other visitors. For shared reviews, add a backend/database or a review service. The “Leave a Google Review” button must use the business's real Google review link; the site's own review form does not publish to Google.

Google ratings use 1–5 stars, not 6. The current website review form supports up to 5 stars.
