REVIEWS IMPORTANT
The review form lets a visitor select 1–5 stars, add a name and feedback, and see reviews stored in that same browser using localStorage. It is a front-end demo; reviews do not automatically appear for other visitors. For shared reviews, add a backend/database or a review service. The “Leave a Google Review” button must use the business's real Google review link; the site's own review form does not publish to Google.

Google ratings use 1–5 stars, not 6. The current website review form supports up to 5 stars.
